Captions for LoRA training, in the browser

CrossTag writes one caption per picture and keeps it in a .txt file with the picture's name, the layout that ai-toolkit, OneTrainer and kohya read. The page has no server: the pictures stay in your folder or in this browser.

Dragging pictures, captions or a ZIP onto the page adds them too.

The desktop app for Windows, macOS and Linux is on the releases page. The code is on GitHub under the MIT License.

Pictures

    Ctrl or Cmd with a click adds a picture to the selection; Shift with a click selects a range. The arrow keys move between pictures.

    Saved while you type. Alt with an arrow key moves to the next or previous picture.

    Where this picture comes from
    Trigger word and model

    The name your LoRA learns, such as "s30ulphoto". The export puts it at the start of every caption. A made-up word works better than a common one, because the model has no old meaning for it to unlearn.

    Tags

    Every part between commas, with how many captions use it. A click shows only the pictures with that tag. Tags used once are marked: they are often typos.

      Rename the files

      Gives every picture and its caption a name with a number, such as seoul-01.jpg and seoul-01.txt. In a folder this renames the files on disk, so keep a backup.

      Check the dataset

      Looks for pictures without captions, pictures smaller than the training size, very wide or tall pictures, the same picture twice, and a mix of file types.

        Dataset card

        The card goes into every export as DATASET.md: who made the dataset, why, and under which license. The source of each picture comes from the fields under "Where this picture comes from".
